# zhestkz-video-processor

Автоматический видеопроцессор для проекта **ЖЕСТЬ KZ** на GitHub Actions.

## Как работает без ручного участия

1. Cloudflare Worker `zhestkz` сам собирает и публикует новость в Telegram.
2. После успешной публикации Worker 5.2 кладёт ту же новость в `/video/jobs`.
3. GitHub Actions автоматически проверяет очередь каждые 5 минут.
4. Если новой задачи нет, workflow быстро завершается без установки FFmpeg/Whisper.
5. Если задача есть, процессор скачивает медиа, делает вертикальный ролик 1080×1920, при наличии аудио распознаёт русскую речь через faster-whisper, прожигает субтитры и сохраняет H.264 MP4.
6. Готовый MP4 и `result.json` сохраняются как GitHub Actions artifact.
7. Обработанный `job_id` записывается в `state/processed.json`, поэтому одна и та же новость повторно не рендерится.

Ручной **Run workflow** для штатной работы не нужен. `workflow_dispatch` оставлен только как диагностический резерв.

## Отказоустойчивость

- protocol-relative media URL (`//...`) нормализуются;
- Telegram emoji-картинки не используются как исходное медиа;
- если медиа-ссылка просрочена, недоступна или файл повреждён, процессор автоматически делает текстовый ролик вместо остановки конвейера;
- при неудаче Whisper ролик продолжает собираться без распознанных субтитров;
- неуспешная задача не помечается обработанной и будет повторно взята следующим автоматическим запуском.

## Текущий выход

Сейчас полностью автоматизирован путь:

`Cloudflare -> Telegram -> video queue -> GitHub Actions -> TikTok-ready MP4`

Непосредственная автопубликация MP4 в TikTok потребует подключения официального TikTok Content Posting API и действующего access token. После подключения этого API финальный шаг можно добавить в тот же workflow без ручного скачивания ролика.
